# Ideas for Fatidique

## Visual & Fun Features

- [ ] **Themes/backgrounds**: Let users pick a theme (party, wedding, vacation, spooky for Halloween, etc.) or upload a custom background image
- [ ] **Confetti/animation when countdown ends**: Celebrate the moment with particles, fireworks, or a fun animation
- [ ] **Sound effects**: Optional alarm or celebration sound when the timer hits zero
- [ ] **Shareable widgets**: Embed code to put the countdown on other websites/blogs

## Practical Features

- [ ] **Recurring events**: "Days until next Friday" or "Time until my birthday (every year)"
- [ ] **Timezone support**: Let viewers see the countdown in their local timezone
- [ ] **"Time since" mode**: Flip the countdown to show elapsed time after the event passes (e.g., "married for 2 years, 3 months...")
- [ ] **Multiple countdowns dashboard**: A page showing all your countdowns at once
- [ ] **QR code generation**: Easy sharing for printed invitations

## Social Features

- [ ] **Comments/guestbook**: Let visitors leave messages on public events
- [ ] **"I'm coming" button**: Simple RSVP without login
- [ ] **Share buttons**: One-click share to social media with a preview image

## Nerdy/Fun Additions

- [ ] **Alternative time units**: "Only 847,293 seconds until vacation!" or "Just 42 sleeps until Christmas"
- [ ] **Progress bar**: Visual representation of how much time has passed vs. remaining
- [ ] **Random event suggestions**: "Create a countdown to..." with fun prompts
- [ ] **Event categories with stats**: "Most popular countdowns right now"
